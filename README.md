Расширение для Google Chrome, возвращающее на Кинопоиск функцию сортировки фильмов по их продолжительности на странице «Буду смотреть»

## 💻Установка
1. Скачаем архив с содержимым репозитория
2. Распаковываем архив
3. В Google Chrome: находим в настройках вкладку "Расширения" -> включаем Режим разработчика -> Нажимаем "Загрузить распакованное расширение"
4. Выбираем папку с распакованным расширением

## 🌐Использование
1. Нажимаем кнопку "Загрузить фильмы"; подгружаются карточки фильмов со всех страниц (предварительно необходимо выбрать старую версию страницы - кнопка внизу сайта)
3. Сортируем по длительности фильма с помощью кнопки "Сортировать по продолжительности". Доступна сортировка по возрастанию и убыванию
